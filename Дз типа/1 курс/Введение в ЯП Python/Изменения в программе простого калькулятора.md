### Исправление ошибок
1. Ошибка представляла собой дублирование кода, которое происходило на этапе когда производились различные вычисления с переданными числами, данную проблему можно решить вынесением частей кода, которые не влияют на конкретное вычисление в рамках условия, в данном случае мы выносим это таким образом: 
   ```python
    a = int(input("Введите число а:"))
    b = int(input("Введите число b:"))
    print("Результат:", a / b)
    input()
    os.system('cls')
    # Превращается в:
    os.system('cls')
    print("Результат:", int(a) / int(b))
   ```
   Здесь также было убрано бесполезное использование input(), которое было заменено на более лучшее решение, где пользователь не будет нажимать дополнительных кнопок. Вынесение же самого кода с вводом чисел было вынесено в более логичное место, все это можно увидеть в коде.
2. Ошибка с вводом не числа в переменные, такие как n, a и b. Данная проблема решается довольно просто, ведь python предлагает удобные методы для форматирования представления переменных при определенных условиях, так мы меняем переменные n, a и b на строковые для проверки их на "число" через метод isdigit() который присущий только для строковых значений, в последующих же математических операциях мы будем преобразовывать их в число с помощью метода int(), использовать его мы можем смело, так как вариант, когда строка является не числом или же не является нужным нам уже обработан. Пример использования:
```python
#Проверка:
if (not n.isdigit() or int(n) != 1 and int(n) != 2 and int(n) != 3 and int(n) != 4 and int(n) != 5):
#Использование в математических операциях:
print("Результат:", int(a) - int(b))
```

### Доработки в программе
Доработки - это чисто мое видение более логического решения в подходе разработки такого калькулятора. Здесь не будет примера кода, только мои мысли, которых я придерживался, когда исправлял код. Весь код будет лежать в pdf, а также внизу данного файла.
1. Использование сразу os.system('cls') и показание результата вместо использование input(), мы можем сразу показать пользователю результат и предлагать ему дальше использовать наш функционал заместо нажатия на input(), даже в настоящем калькуляторе используется этот подход, пользователь не будет нажимать ненужную кнопку для того чтобы продолжить пользоваться калькулятором, ему достаточно просто увидеть ответ и делать дальнейшие вычисления.
2. Перенес else блок в if(), потому что такая проверка мне кажется более логичной и понятной с точки зрения понимая кода, тебе не нужно будет при следующем заходе в код думать, что пользователь еще и должен ввести число, а не только число, которое не входит в радиус предлагаемого выбора.
3. Использование continue в проверке чисел a и b. Ну как я считаю использование continue это самое логичное действие, ведь если в данные переменные переданы не числа, то continue пропустит все блоки кода находящиеся после него и как бы вернется в блок-родитель кода, в нашем же случае это повторный вызов цикла while, который предложит заново ввести числа.

## Код
```python
import os, time
enabled = True
os.system('cls')
print('Простой калькулятор.')

while enabled:
    print("1. Сложить два числа.")
    print("2. Вычесть два числа.")
    print("3. Умножить два числа.")
    print("4. Разделить число а на в.")

    n = input("Введите номер действия: ")
    if (not n.isdigit() or int(n) != 1 and int(n) != 2 and int(n) != 3 and int(n) != 4 and int(n) != 5):
        os.system('cls')
        print("Повторите ввод!")
    else:
        a = input("Введите число а:")
        if (not a.isdigit()):
            os.system('cls')
            print('Повторите ввод!')
            continue
        b = input("Введите число b:")
        if (not b.isdigit()):
            os.system('cls')
            print('Повторите ввод!')
            continue
        if int(n) == 1:
            os.system('cls')
            print("Результат:", int(a) + int(b))
        elif int(n) == 2:
            os.system('cls')
            print("Результат:", int(a) - int(b))
        elif int(n) == 3:
            os.system('cls')
            print("Результат:", int(a) * int(b))
        elif int(n) == 4:
            os.system('cls')
            print("Результат:", int(a) / int(b))
        elif int(n) == 5:
            print('До скорых встреч!')
            enabled = False
```
