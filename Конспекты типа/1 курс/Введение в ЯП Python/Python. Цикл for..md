### 1. Цикл
Цикл - повторяющаяся последовательность событий, процессов или действий, они образуют заверщённый круг развития. Является управляющей конструкцией, которая многократно повторяет блок кода внутри.
### 2. Цикл for
Цикл for - это цикл, который повторяется указанное количество раз. Этот цикл пробегается по набору значений, помещает каждое значение в переменную, а затем в цикле мы можем производить различные действия с ней. Имеет такой синтаксис:
```python
`for` `переменная` `in` `набор_значений:'
    `инструкции`
```
### 3. Итерируемый обьект
Итерируемый обьект - это сущность, которую можно перебирать по одному элементу. К таким сущностям относятся массивы, строки, а также если написать правильный цикл то можно написать перебор каждой отдельный цифры в числе.
```python
sda = [] # массив
txt = "Привет" # строка
number = 12345 # число
```
### 4. Переменная цикла
Переменная цикла - специальная переменная для управления повторениями внутри самого цикла. Зачастую принято использовать букву i в цикле for например, потому что это сокращенно iteration. Обычно в переменный цикла for задают либо индекс, либо количество операций, которые необходимо сделать до какого-то значения
```python
for i in range(): # i тут и является переменной цикла.
	#smth
```
### 5. Итерация
Итерация - повторение какого-либо действия или один шаг в циклическом процессе. А именно в Python это является одним проходом цикла, если он успешно выполнил и дошел до конца блока кода например того же for.
```python
for i in range(1, 5):
	print("Hello")
	# здесь закончилась итерация, ведь дальше нету блока кода и это конец констркуции for
```
### 6. Вложенный цикл
Вложенный цикл - цикл, который находится в теле другого цикла. Пример конструкции:
```yoptascript
`for` `c1` `in`  `"ab"``:`
    `for` `c2` `in` `"ba"``:`
        `print``(f``"{c1}{c2}"``)`
```
### 7. Оператор break
Оператор break - осуществляет выход из цикла.
```python
number = 0
while number < 5:
    number += 1
    if number == 3 :    # если number = 3, выходим из цикла
        break
    print(f"number = {number}")
```
### 8. Оператор continue
Оператор continue - выполняет переход к следующей итерации цикла.
```python
`number` `=` `0`
`while` `number <` `5``:`
    `number` `+``=` `1`
    `if` `number` `=``=` `3` `:`    `# если number = 3, переходим к новой итерации цикла`
        `continue`
    `print``(f``"number = {number}"``)`
```
### 9. Блок else у цикла
Для цикла while также можно определить дополнительный блок else, инструкции которого выполняются, когда условие равно False.
```python
number = 1

while number < 5:
	print(f"number = {number}")
	number+=1
else:
	print(f"number = {number}. Работа цикла завершена")
print("Работа программы завершена")
```
### 10. Функция range()
range() - принимает в себя 3 параметра, но также имеет два конструктора, где возможны как два параметра, так и 3. Позволяет задать циклу for шаг и ограничения.
```python
# два параметра
for i in range(1, 5): # шаг 1(даже если мы не указываем шаг, то он изначально задается в конструкции с двумя параметрами как с шагом в 1)
	print("Hi")
# три параметра
for i in range(1, 5, 2): # шаг 2
	print("Hello")
```
