### Типы данных
Пример из реальной жизни - есть некоторый товар с определенной ценой. Например, энциклопедия стоимостью 1249 рублей. Добавив ластик за 10 рублей в список покупок мы можем рассудить о допустимости некоторых операций.

Так например, в чеке общая сумма будет 1259 рублей. Числа в данном контексте можно было сложить. Однако названия товаров (текст) сложить с ценами или друг с другом нельзя.

Такие действия как раз и определяются при помощи типов данных.

Тип данных - множество значений и набор допустимых операций над ним. Отвечает на вопрос, что можно делать со значением: числа можно складывать, строки - склеивать, списки - обьединять. В Python тип реализуется *классом*.

```Java
String name = scanner.nextLine("Введите свое имя: ");
System.out.println(name + " привет!");
```
Чтобы проверить тип некороторого значения используется функция **type()**

```python
print(type(42)) #<class 'int'>
print(type("sos")) #<class 'str'>
```

Базовые типы данных
- int - целые числа.
- str - строки. Всегда записываются в кавычках! Пр. "Текст"
- float - числа с плавающей точкой. Записываются с использованием точки. Пр. 3.14
- bool - логический тип данных. true or false.

Литерал - запись фиксированного значения прямо внутри кода. 

**Значение** - конкретные данные, которые хранятся в памяти компьютера и оперируются программой.
**Объект** - абстракция для представления данных, где все сущности являются экземпляром какого-либо класса.

### Переменные

Переменная - именованная ссылка на объект в памяти компьютера. Сама переменная не хранит значения, а лишь указывает, где лежит обьект, поэтому две переменные могут указывать на один объект.

```python
x = 10
```
Запись состоит из следующих частей:
1. Идентификатор (имя). Начинается с буквы или знака _ , далее допускаются буквы, цифры и знаки. Python - регистрозависимый, т.е name и NAME - разные переменные. Использование ключевых слов в названии переменных запрещено.
2. Оператор присваивания. Выполняет функцию связывания имени с объектом. Записывается как =
3. Обьект, задаваемый литералом или некоторым значением.
