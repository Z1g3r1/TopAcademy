### Что такое циклы в программирование?

Цикл - это управляющая конструкция, которая позволяет многократно повторять один и тот же блок команд (тело цикла) до тех пор, пока выполняется определенное условие или пока не будет выполнено заданное количество повторений.

#### Зачем нужны циклы?

В жизни мы постоянно сталкиваемся с повторяющимися действиями. В программировании, если нужно выполнить одно и то же действие много раз, вместо того чтобы писать один и тот же код снова и снова, мы используем цикл.

### Виды циклов

1. Цикл For - повторение кода известное количество раз, а также перебор для элементов коллекций. Синтаксис:
   ```python
   for переменная in последовательность:
	   тело цикла
   ```
   Проверка перед каждой итерации, счетчик сам берет значение из последовательности.
2. Цикл While - повторение кода до тех пор, пока условие истинно. Синтаксис:
   ```python
   while условие:
	   тело цикла
   ```
   Проверка перед каждой итерацией, нужно самим изменять переменную самому.
3. Оператор continue не является циклом, а лишь дополнением к нему, если код выполнил или нашел то или иное переданное в условии, то можно продолжить выполнение кода после конструкций условий. Синтаксис:
   ```python
   for i in 'Hello, world':
	   if i == "o":
		   continue
		print(i*2, end="")
   ```
4. Оператор break досрочно завершает цикл. Синтаксис:
      ```python
      for i in 'Hello, world':
	      if i == 'o':
		    break
		print(i * 2, end = "")
      ```
5. Ключевое слово else, используется в цикле для обработки исключения. Синтаксис:
   ```python
   for i in "Hello, world":
	   if i == "i":
		   break
		else:
			print("Буквы i в строке нету!")
   ```
