### Определения 
Программный продукт (ПП) - совокупность программных кодов, данных и программной документации (ПД), предназначенная для решения определенных задач.

Чем отличается ПП от ПО?
ПО - общая категория для абсолютно всех программ на устройстве (утилиты, драйвера, ОС и ее компоненты), а ПП - только те программы, с которыми пользователь взаимодействует напрямую для решения своих конкретных задач. Также ПП относится к прикладному ПО.

### Виды ПО
 - Прикладное ПО
 - Системное ПО
 - Инструментальное ПО (для разработки)

### Структуры программ
- Интерфейс пользователя (UI/UX - User Interface/User experience) - графическая оболочка или консоль для ==взаимодействия== между пользователем и программой.
- Бизнес-логика (ядро) - набор алгоритмов и данных, реализующих основную функциональность и обработку данных.
- Работа с данными - базы данных, файлы, хранилища и т.п, где обрабатывается и сохраняется информация.

Все перечисленные уровни/этапы структуры соответствует модульной архитектуре - программа состоит их независимых логических частей.

Информация о стадиях и этапах разработки находится в файле [[Жизненный цикл ПО]].

### Стадии и этапы разработки программной документации
ЕСПД - Единая система программной документации. Им определены следующие стадии создания программ:
1. Техническое задание - разработка согласования и утверждение ТЗ на программу.
2. Внедрение - подготовка объекта к внедрению, приемочные испытания и сдача ПО в эксплуатацию.
Подробнее изучить каждый из этапов можно по ГОСТ 19.102-77 или его актуальному аналогу.
