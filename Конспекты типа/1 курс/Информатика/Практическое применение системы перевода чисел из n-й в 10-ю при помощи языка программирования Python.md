```python
def revo(number: str, quad: int) -> str:
    j = len(number) - 1
    sum = 0
    for i in range(len(number)):
        sum += int(number[i]) * (quad**j)
        j = j - 1
    return str(sum)
def any_to_any(number: str, from_base: int, to_base: int) -> str:
    dec_number = int(revo(number, from_base)) # в 10чной системе 131 -> 29

    if dec_number == 0:
        return 0
    
    digits = "0123456789ABCDEF"
    result = ""
    while dec_number > 0:
        result = digits[dec_number % to_base] + result # digits[29 % 7 == 4] = "4" + ""
        dec_number //= to_base # теперь 4
    return result
```

Здесь у меня находятся два реализованных метода, которые работают в совокупе чтобы перевести число из любой системы в любую другую.
Первый метод я использую для того, чтобы перевести число пользователя в десятичную систему из любой другой, это работает так: берем число по индексу, а потом превращаем его в Integer, чтобы умножить на степень счисления в степени j (потому что идем сначала, а не с конца и убавляем j для имитации индексации слева направо), а позже уменьшаем саму эту степень потому-что идем дальше по числам, в итоге мы получаем число в его десятичной системе счисления.
Следующий же метод позволяет перевести это число в десятичной системе в любую другую, он работает по системе деления столбиком: сначала мы вызываем метод, который позволит перевести введенное пользователем число в десятичную систему используя уже готовый метод. Дальше мы проверяем если число будет 0 в десятичной, значит оно будет 0 и в любой другой. Дальше мы используем деление столбиком, которое реализовано с помощью цикла while, а именно на каждой итерации мы записываем получившееся число в result, который обьявлен строкой, потому что не все системы счисления используют цифры(тут используется индекс в уже обьявленой строке со все возможными символами систем счисления). После чего мы также меняем число, потому что мы поделили его в столбик, пока оно не будет меньше или равно нулю, а потом выдаем результат числа, которое получилось.
